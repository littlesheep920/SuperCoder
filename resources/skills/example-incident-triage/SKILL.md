# Incident Triage (example)

## When to use

When an alert fires and the owner needs a shared situation summary.

## Structure

1. **Impact** — who is affected, and how they notice it.
2. **Timeline** — first symptom, detection, acknowledgement.
3. **Blast radius** — which services and tenants.
4. **Next step** — exactly one diagnostic action with an owner.

## Rules

Name one next step, not a list. An incident note with five unclear actions is
worse than one with a single clear one.
