# Example Regression Scope Selection

## When to use

Selects the smallest test set that still covers a change's risk surface.

## Steps

1. Collect the declared input.
2. Map changed paths to owning tests, then widen only where the mapping is missing.
3. Report each finding with the exact item it refers to.

## Limits

Illustrative sample content. Do not act on the output without a human decision.
