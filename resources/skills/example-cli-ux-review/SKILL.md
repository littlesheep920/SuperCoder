# Example CLI UX Review

## When to use

Reviews a command-line interface for discoverability, error messages, and exit codes.

## Steps

1. Collect the declared input.
2. Check help output, then confirm each failure exits non-zero with an actionable message.
3. Report each finding with the exact item it refers to.

## Limits

Illustrative sample content. Do not act on the output without a human decision.
