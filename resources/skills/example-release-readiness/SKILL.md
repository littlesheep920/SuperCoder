# Release Readiness Check (example)

## Gates

| Gate | Evidence required |
|---|---|
| Tests | A recorded run with its commit hash |
| Migration | A rehearsed rollback |
| Rollback | A named operator and a time estimate |
| Communication | A published change note |

## Reporting

Mark each gate met, missing, or waived-with-justification. Never mark a gate met
without citing the evidence that satisfied it.
