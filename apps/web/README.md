# Web 应用包边界

`apps/web` 是 SuperCoder 面向工程师、资源维护者、审核者和平台运营者的 Web 工作台预留应用包。本文冻结阶段 0 的前端契约；本目录当前**不包含、也不声称包含可运行或已构建的 Web 应用**。

## 阶段 0 契约

阶段 0 定义 Web 作为平台展示与人工交互层，而不是事实源或执行引擎：

- 仅通过 API 的 REST/SSE 契约读取和变更平台状态。
- 所有资源、版本、权限、审核、任务、评测和审计信息均以服务端返回为准。
- UI 必须区分真实数据、脱敏 demo、加载、空、失败、权限拒绝、取消、重试和恢复状态。
- 未实现的后端能力不得用可点击假按钮、永久 Mock、硬编码成功结果或 metadata-only 页面冒充完成。
- 外部 LLM、Embedding、Rerank 和运行环境适配状态必须如实展示；未完成适配器标记为 `INCOMPLETE`，不得展示为 `SUPPORTED`。

## 职责

阶段 1 及后续实现后，本包负责：

1. 提供能力资产中心、能力发现台、资源登记向导、资源详情与版本 Diff。
2. 提供 Workflow Studio、任务监控、评测中心、审核界面和治理驾驶舱。
3. 收集并本地校验用户输入，但始终接受 API 的权威校验与权限判定。
4. 展示候选能力的匹配理由、版本、依赖、权限和运行环境兼容性，不把推荐包装成自动批准。
5. 为关键动作提供明确的确认、审批、取消、重试和错误恢复交互。
6. 支持桌面端和窄屏、键盘操作、可访问性语义及稳定的加载反馈。
7. 对 Job 的进度、事件和最终产物进行可追踪展示，不根据动画或前端计时器推断任务已完成。

## 明确不负责

- 不直接连接 MySQL、Redis、Qdrant，也不直接读取或修改资源 Git 仓库。
- 不在浏览器中执行受控 Worker 任务、任意代码、服务端工具或发布动作。
- 不在前端保存 Secret，不向日志、URL、浏览器持久存储或错误信息写入凭据。
- 不自行判定权限、审核通过、资源发布、Workflow 成功或评测达标。
- 不用静态页面、占位字符串或伪造指标替代真实 API、数据集和可复现实验结果。

## 与其他应用包的关系

- `apps/api` 是 Web 唯一的平台业务接口；前端类型与客户端应从冻结的 OpenAPI 契约生成或保持一致。
- `apps/worker` 对 Web 不可直接寻址；后台执行状态必须经 API 的 Job 和 SSE 契约暴露。
- `resources` 中的正文在 Web 中作为不可信数据展示；其中看似系统指令的 Prompt Injection 不得改变应用控制流、权限或系统策略。

## 阶段 1 实现入口

阶段 1 将在本目录初始化 Vue 3 + TypeScript 应用，约定源码入口为 `apps/web/src/main.ts`，并划分 `views`、`components`、`api`、`stores`、`router` 和 `types`。首批实现应以能力资产中心和正式 API 客户端为入口，同时覆盖正常、空、加载、错误、拒绝和恢复路径；只有构建、交互和接口集成验证通过后，才可宣称 Web 应用可运行。

## 当前完成声明

本 README 仅证明 Web 包的职责、信任边界和后续入口已冻结。它不证明 Vue 依赖已安装、页面已实现、生产构建成功、API 已联通或任何用户流程已经验收。
